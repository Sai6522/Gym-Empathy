# EmpathyGym 🎧

**Voice-first customer support training simulator** — practice handling difficult customers using real-time AI personas, live frustration tracking, and scored performance reports.

🚀 **Live Demo**: [https://empathy-gym-c5f7a.web.app](https://empathy-gym-c5f7a.web.app)

---

## Features

- **4 AI Customer Personas** — Frustrated Senior, Irate Buyer, Confused Business Owner, Repeat Caller
- **Real-time Voice** — Speak via microphone; AI customer responds aloud using browser-native Web Speech API
- **Frustration Meter** — Live 1–10 gauge tracking the customer's patience after every response
- **Live Transcript** — Chat-style log of the full conversation
- **AI Scorecard** — Empathy Score, Clarity Rating, and 3 coaching recommendations generated by Gemini
- **Firebase Logging** — Save session transcripts and scores to Firestore

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18 + TypeScript + Vite |
| Voice | Web Speech API (browser native, free) |
| AI | Google Gemini 2.5 Flash |
| Database | Firebase Firestore (free tier) |
| Hosting | Firebase Hosting (free tier) |

## Run Locally

```bash
git clone https://github.com/Sai6522/Gym-Empathy.git
cd Gym-Empathy
npm install
```

Create `.env.local`:
```
VITE_GEMINI_API_KEY=your_gemini_api_key
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_STORAGE_BUCKET=...
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
```

```bash
npm run dev
```

Open **http://localhost:5173** in Chrome (required for Web Speech API).

## Deploy

```bash
npm run build
npx firebase deploy --only hosting
```
